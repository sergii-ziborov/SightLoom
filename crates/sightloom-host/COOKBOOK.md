# Host weights cookbook

SightLoom **never** ships neural-network weights. Hosts own models, licenses,
GPUs, and download policy. This guide closes the practical **photo → rank** path
with `sightloom-host`.

## Boundary

```text
your ONNX / detector / decode
        │
        ▼
 sightloom-host   (ModelManifest, fetch, preprocess, adapters)
        │
        ▼
   sightloom      (IndexSession rank / memory / tracks)
```

| Layer | Owns |
| --- | --- |
| Host binary | weight URLs, secrets, CUDA/ORT choice, blur, video I/O |
| `sightloom-host` | config, cache, SHA-256 check, tract ONNX (optional), reference fakes |
| `sightloom` | embeddings → gallery search, tracks, anomalies |

## Features

| Feature | Use when |
| --- | --- |
| `std` (default) | reference models + manifest + integrity |
| `onnx` | real ONNX via pure-Rust **tract** |
| `download` | `HttpModelFetcher` GET `ModelSpec.uri` |
| `image-decode` | JPEG/PNG `PhotoView::encoded` |
| `full` | all of the above |

## 1. Manifest JSON

Write a versioned inventory (example generated by the `weights_cookbook` example):

Checked-in skeleton: [`examples/models.manifest.json`](./examples/models.manifest.json).

```json
{
  "version": 1,
  "cache_dir": ".sightloom-models",
  "notes": "person_detect + person_reid required; face_embed optional",
  "models": [
    {
      "id": "person_detect",
      "task": "person_detect",
      "format": "onnx",
      "embedding_dim": 0,
      "local_path": ".sightloom-models/person_detect.onnx",
      "uri": null,
      "sha256": null
    },
    {
      "id": "person_reid",
      "task": "person_reid",
      "format": "onnx",
      "embedding_dim": 512,
      "local_path": ".sightloom-models/person_reid.onnx",
      "uri": null,
      "sha256": null
    },
    {
      "id": "face_embed",
      "task": "face_embed",
      "format": "onnx",
      "embedding_dim": 512,
      "local_path": ".sightloom-models/face_embed.onnx",
      "sha256": null
    }
  ]
}
```

Each spec carries `id`, `task`, `local_path` **or** `uri`, and optional `sha256`.

Rust:

```rust,ignore
use sightloom_host::{
    FilesystemFetcher, ModelFetcher, ModelManifest, resolve_manifest,
};

let manifest = ModelManifest::load_path("models.manifest.json")?;
// Offline: place files yourself
let resolved = resolve_manifest(&manifest, &mut FilesystemFetcher)?;
// Online (feature download):
// let resolved = resolve_manifest(&manifest, &mut HttpModelFetcher::default())?;
```

`ModelSpec.sha256` (optional) is verified after every resolve/download.

## 2. Place or download weights

**Option A — local drop-in**

```text
.sightloom-models/
  person_reid.onnx
  person_detect.onnx
  README.txt          # from write_cache_readme
```

**Option B — HTTP** (feature `download`, trusted URIs only)

```rust,ignore
use sightloom_host::{HttpModelFetcher, ModelManifest};

let m = ModelManifest::load_path("models.manifest.json")?;
let paths = m.ensure_all(&mut HttpModelFetcher::default())?;
```

Downloads write `{id}.onnx` via atomic `.part` rename.

## 3. ONNX contracts (tract)

Two required files (never committed to this repo):

| File | Task | Input | Output | Preprocess |
| --- | --- | --- | --- | --- |
| `person_detect.onnx` | `person_detect` | NCHW RGB `f32` | YOLO `[1,4+C,N]` / `[1,N,5+C]` / `N×6` (`x1,y1,x2,y2,score,class`) | [`PreprocessConfig::yolo_detect`] (letterbox, `/255`, pad 114) + [`decode_detector_output`] |
| `person_reid.onnx` | `person_reid` | NCHW RGB `f32` | embedding `f32` (any `D`; truncated/padded to `embedding_dim`) | ImageNet mean/std, typically `128×256` (OSNet crop) |
| `face_embed.onnx` (optional) | `face_embed` | same embed contract | embedding `f32` | typically `112×112` ImageNet |

`OnnxEmbedder` L2-normalizes the vector. `OnnxDetector` inverts letterbox and runs class-aware NMS.

**Recommended host pair** (you download and license; we do not vendor):

- Detector: **YOLOv8n** (COCO; keep class `0` person, or export person-only)
- Re-id: **OSNet x1.0** (512-d, ImageNet-normalized `256×128` / `128×256` crop)

```bash
cargo run -p sightloom-host --features onnx --example onnx_detect
cargo run -p sightloom-host --features full --example host_onnx_pipeline
```

## 4. Encoded photos

The Host photo path (`enroll_photo` / `search_photo_jpeg`) **requires**
feature `image-decode`. JPEG/PNG bytes go in `PhotoView { encoded }`.

Without `image-decode`, pass `PhotoView::frame` (raw RGB) or accept the
reference embedder’s byte-fingerprint fallback (not for production re-id).

## 5. End-to-end checklist

1. `cargo run -p sightloom-host --example weights_cookbook -- ./host-models`
2. Edit `models.manifest.json` — set `uri` and/or copy `.onnx` files
3. Optional: compute digest → set `sha256`:

   ```bash
   # any SHA-256 tool; or call file_sha256_hex in a small host tool
   ```

4. Resolve: filesystem or `HttpModelFetcher`
5. Swap into the pipeline (no reference fakes):

   ```rust,ignore
   let mut pipe = HostPipeline::from_onnx_cache("host", ".sightloom-models")?;
   let sid = pipe.enroll_photo(jpeg_bytes)?;
   let hits = pipe.search_photo_jpeg(jpeg_bytes, 5)?;
   let tracked = pipe.ingest_frame(stamp, &rgb_frame)?;
   pipe.save_package("./vision-index")?;
   ```

   Or `HostPipeline::from_manifest(name, &manifest)`.

6. Evidence: `write_evidence_pack` for MOT/re-id harness (not leaderboard claims)

## Honest claims

| Path | Accuracy |
| --- | --- |
| Reference embedders | wiring smoke only |
| Your ONNX + tract | **your** model quality |
| Manifest + SHA-256 | integrity of the file, not model correctness |
| Synthetic evidence pack | CI harness, not MOT17 scores |
